# Custom Simulator

Numerical simulation of a rigid underwater vehicle using Fossen's 6-DOF hydrodynamic model.


## Features

- 6-DOF rigid body dynamics
- Fossen vectorial hydrodynamics
- RK4 state integration
- Modular simulation architecture
- Configurable vehicle parameters
